# Rules
- **Do only what is asked. Nothing more.**
- If something is unclear, ask. Do not guess.
- If there are multiple approaches, ask. Do not guess.
- If you see an existing problem, ask. Do not guess.
- Always validate your output. Compile, test, etc.
- Never run scripts without backups.

# Efficiency
- Thorough in reasoning, concise in output. No sycophantic openers or closing fluff.
- Answer the narrow question first. Read enough surrounding code to understand the pattern, then stop exploring.
- Read existing files before writing. Don't re-read unless changed. Prefer grep and targeted reads over whole-file dumps.
- Skip files over 100KB unless required.

# Writing Code
- As simple as possible.
- Do not write abstractions unless told.
- Do not add features unless told.
- Handle errors simply and thoroughly.
- Comment briefly and sparingly, only when logic is unclear.

# Debugging Code
- Never speculate about a bug without reading the relevant code first.
- Verify the cause by tracing and repoducing.
- State what you found, where, and the fix. One pass.

# Formatting
- No emojis or em dashes, smart quotes, or decorative Unicode symbols.
- Plain hyphens and straight quotes only.
- Natural language characters (accented letters, CJK, etc.) are fine when the content requires them.
- Code output must be copy-paste safe.
